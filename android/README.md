# Android runtime smoke project

This directory is a deliberately minimal CI-only Android application used to prove ADR 0002's Kotlin/Rust runtime boundary before any production Android application or secret-bearing JNI API is introduced.

The smoke app:

- uses the accepted Phase-1 baseline (`minSdk 26`, `compileSdk 37`, `targetSdk 37`);
- uses Android Gradle Plugin 9.3.0 with its built-in Kotlin support;
- packages the Rust `kdbx-fortress-android-jni` shared library generated by CI;
- loads the library through `System.loadLibrary`;
- calls `NativeBridge.nativeCapabilityProbe` for the core ABI, adapter ABI and an unsupported request;
- writes only `PASS` or a non-secret exception class to app-private storage for CI to inspect.

It intentionally contains no password, keyfile, vault-open, handle, entry-field, persistence, network, telemetry or Autofill API. It is not the production Android app skeleton.
